# 사건 풀

이 문서는 게임 내에서 발생 가능한 돌발 사건 전체 목록을 정의한다.
각 사건의 상세 분기 구조는 [`02_징조_사건_결과_체인.md`](./02_징조_사건_결과_체인.md)를 참조한다.

---

## 사건 ID 체계

```
EVT - [유형 코드] - [번호]

유형 코드:
  M  = 멘탈 (mental)
  C  = 갈등 (conflict)
  L  = 이탈 (leave)
  R  = 루머·스캔들 (rumor)
  X  = 외부 변수 (external)
  B  = 호재 (bonus)
```

## 사건 강도 분포 요약

| 강도 | 창작 루프 영향 범위 |
|------|---------------------|
| 약 | 해당 PHASE 내 소규모 조정으로 수습 가능 |
| 중 | 해당 PHASE 계획 일부 재설계 필요. 이후 PHASE에 잔여 영향 발생 가능 |
| 강 | 창작 루프 전체 계획 재검토 또는 멤버 구성 변화 위험 |
